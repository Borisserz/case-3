# Gotchas (living list)

1. **Preview ≠ PDF** — Liber shows TeX blocks; trust PDF slider / download.  
2. **Sticky downloads** — must stay `position: static` at end of report.  
3. **horizontal_bar + pale rgba** — harden solidifies; don't regress canvas height.  
4. **tabularx cell-per-line** — without `repair_tabularx_row_breaks` → Misplaced `&`.  
5. **api --reload** — kills long pipelines; prod desk off.  
6. **KPI type + bar canvas** — coerce rebuilds KPI HTML.  
7. **Chart type badge** — hidden from users; keep in `title=` / edit sheet only.  
8. **Image edit fallback** — worker may regenerate without ref photo.  
9. **Fonts** — PDF DejaVu; DOCX reference still Times until D1.  
10. **PPTX** — not in product; see parked-pptx.md.
