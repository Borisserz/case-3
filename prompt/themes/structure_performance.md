# Structure — Performance / channel (Julius Bold Signal DNA)

Growth intelligence pack (≈10–12). Hard max 12. Numbers ⊆ Source.

1. `title` — domain label (Marketing / Channel / Performance)
2. `section` — executive signal (one insight line)
3. `chart_hero` — spend vs return
4. `scorecard` — efficiency KPIs from Source
5. `chart_split` — return / efficiency trend
6. `table_hero` — channel comparison
7. Region / segment signal — `card_row` or `chart_hero`
8. Top campaigns — `table_hero`
9. Budget reallocation — `callout` (fund a test, not a wholesale shift)
10. Recommendations — `bullets`
11. 90-day activation roadmap — `card_row`
12. `closing` — data & definitions caveats from Source only

High-contrast narrative. Prefer tables + charts; minimize fluffy bullets.
