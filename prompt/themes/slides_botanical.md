# Theme overlay — botanical (Dark Botanical / VESPER DNA)

Narrative tone: luxury editorial product / brand launch. Deep forest, ivory type, brass foil. Quiet ritual voice — not clinical wellness claims.

- Prefer **10–12** slides; open with `title` (hero media when a figure exists) then story → product → plan → close.
- Title `takeaway`: short stacked lines (brand promise), not a data dump. Attach `media_id` on title/closing for full-bleed product photo.
- Use `callout` for the positioning line; **`card_row`** for audience / launch phases / learning cadence (3 cards + gold `caption` gate, e.g. VALIDATION GATE…).
- `scorecard` / `kpi_row` for illustrative targets (label as planning goals when Source is conceptual).
- `table_hero` for channel / budget rows; closing slide returns to the ritual line.
- Numbers only from Source; if illustrative, say so in takeaway/caption.
