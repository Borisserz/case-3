# Structure — Board Update (Northstar)

**Signature:** callout ask early · scorecard · bridge `table_hero` · decisions.  
Navy + teal. Numbers ⊆ Source.

1. `title` — thesis + 2–3 hero KPIs
2. `callout` — **board ask** (do this early)
3. `scorecard` — actual vs plan
4. `chart_hero` — trajectory
5. `table_hero` — ARR bridge / plan grid
6. `chart_split` or second table — retention / GTM
7. `table_hero` — Q+1 plan (owner · measure)
8. `card_row` — risks + ask + DECISION caption
9. `closing` — hero ARR + definitions

Executive density; sharp tables. Not chart-first performance DNA.
