# Structure — Board Update (Julius Northstar DNA)

**Do not invent numbers.** Arc for a quarterly board pack (≈10–12 slides).

Mandatory shape (adapt to Source; skip a step only if Source has no data):

1. `title` — takeaway title (insight, not «Board update»)
2. `scorecard` — plan vs actual KPIs with `delta`/`status` when Source allows
3. `chart_hero` or `table_hero` — ARR / primary metric trajectory or bridge
4. `table_hero` — bridge / drivers breakdown if Source has rows
5. Retention / health — `chart_split` or `scorecard`
6. GTM / pipeline — `table_hero` or `card_row`
7. Product / delivery — `card_row` or `bullets`
8. Cash / efficiency — `chart_hero` or `scorecard`
9. Next-quarter operating plan — `table_hero` with targets
10. Priorities & owners — `card_row` (3 owned bets) + gold `caption` gate if useful
11. Board ask / decisions — `callout` or `closing` with clear asks
12. Optional appendix — definitions as `bullets`/`table_hero` only if Source defines terms

Rules:
- Chapter kickers like `01 / EXECUTIVE SCORECARD` via `kicker` + optional `chapter`
- Every content slide: **title = insight**; detail in takeaway/body/KPIs
- Prefer ≥2 native-friendly charts + ≥1 table when Source supports
